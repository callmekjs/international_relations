# Claude Design 프롬프트 — 외교백서 「외교정책 기조」

아래 전체를 Claude Design 에 그대로 붙여 넣는다. `data.json` 을 함께 올린다.

---

## 무엇을 만드는가

대한민국 외교백서 1998~2025년(28개년)의 **「외교정책 기조」 절 한 곳만** 모아,
정권 교체가 한국 외교의 우선순위 서술을 어떻게 바꾸고 무엇을 바꾸지 못하는지
독자가 **스스로 읽어내게** 하는 웹 화면.

정부는 해마다 그 해 외교의 우선순위를 **번호를 붙여 인쇄**한다. 이 서비스가 보여주는
숫자는 오직 그 번호다. 우리가 계산한 지표가 아니라 외교부가 매긴 순서다.
**그 번호가 이 프로젝트의 유일한 척추다.**

### 실제로 확인된 것 — 이 화면이 드러내야 할 장면

한반도·북핵 줄기에 인쇄된 번호(26개년 원문 대조 완료):

```
1998  2      2005  1      2012  1      2019  1
1999  1      2006  1      2013  1      2020  2
2000  1      2007  ―      2014  1      2022  1
2001  1      2008  1      2015  2      2023  1
2002  1      2009  1      2017  2      2024  1
2003  1      2010  1      2018  1      2025  4
2004  1      2011  1
```

대부분 1번이지만 **다섯 번 밀렸다.** 그리고 밀린 이유가 서로 다르다.

| 연도 | 1번을 차지한 것 | 무슨 일이 있었나 |
|---|---|---|
| 1998 | 경제위기 극복 및 재도약 기틀 마련 | 외환위기 |
| 2015 | 전략적 로드맵에 따른 주변국 외교 | — |
| 2017 | 주변 4국과 정상외교 공백 복원 | 탄핵으로 정상외교 공백 |
| 2020 | 우리 국민의 생명과 안전 보호 | 코로나19 |
| **2025** | 국익 중심 실용외교 기반 구축 | **외부 충격 없이 4번까지** |

**독자가 이 대비를 스스로 보게 하는 것이 이 화면의 목표다.**
1998·2020년은 외부 충격이 밀어냈고 2017년은 정권 공백이 밀어냈다.
2025년만 그런 사정 없이 내려갔고, 게다가 2번이 아니라 4번이다.
이 차이를 우리가 말로 설명하면 안 된다(규율 3). 배치로 보여줘야 한다.

## 누가 쓰는가

외교부·공무원, 정책 실무자, 사회과학 연구자와 학생.
**인용하고 반박당할 수 있는 자료**를 다루는 사람들이다. 예쁜 것보다 근거로 쓸 수 있는
것이 우선이다. 화면의 모든 문장은 원문과 쪽수로 되짚어 갈 수 있어야 한다.

## 데이터 계약 — 반드시 지킨다

### 1. 절대 하드코딩하지 않는다

**모든 제목·인용문·번호·연도·정부명은 `data.json` 에서 읽는다.**
어떤 값도 컴포넌트·CSS·상수에 박지 않는다. 연도가 늘거나 항목이 채워져도
**화면 코드는 한 줄도 고치지 않아야 한다.**

지금 `data.json` 은 28개년 중 16개년만 항목이 채워져 있다. 나머지는 앞으로 채워진다.
그때 화면이 저절로 메워져야 한다.

### 2. `data.json` 구조

```jsonc
{
  "meta": {
    "schemaVersion": 1,
    "builtAt": "2026-08-15",
    "coverage": { "from": 1998, "to": 2025, "withPriorities": 16, "total": 28 }
  },

  "editions": [{            // 발간분 하나 = 대상 연도 하나. 28개 전부 존재한다
    "coverageYear": 2013,
    "title": "2014 외교백서",       // 표지 제목 (대상연도+1인 것에 주의)
    "publishedYear": 2014,
    "administration": "박근혜",
    "brand": "국민과 함께 하는 신뢰외교",   // 그 정부가 내건 이름. 없으면 null
    "section": { "chapter": 1, "section": 2, "label": "외교정책 기조", "page": 23 },
    "markStyle": "bullet",          // 아래 §markStyle 참조
    "status": "verified",           // 아래 §status 참조 — 화면 분기의 핵심
    "sourceFiles": ["2014 외교백서_제1장.pdf"],
    "note": "6개 추진과제. ▲ 글머리 기호로 나열한 뒤 …"
  }],

  "priorities": [{          // 기조 절의 항목 하나
    "id": "2013-1",
    "coverageYear": 2013,
    "ordinal": 1,                   // **문서에 인쇄된 번호**
    "ordinalSource": "기조절",       // "기조절" | "시책절" — 번호를 어느 절에서 가져왔나
    "title": "북핵문제 진전을 위한 동력 강화",
    "quote": "신정부는 '국민과 함께 하는 신뢰외교' 기조하에 ▲북핵문제 …",
    "stream": "peninsula",
    "source": { "edition": "2014 외교백서", "chapter": 1, "section": 2, "page": 23 },
    "flags": ["lead-only"]          // 아래 §flags 참조
  }],

  "streams": [{             // 여러 해에 걸친 같은 갈래. 사람이 배정했다
    "id": "peninsula",
    "label": "한반도·북핵",
    "note": "북한 비핵화, 남북관계, 한반도 평화체제",
    "members": ["1998-2", "1999-1", "2001-1", "2003-1", "2013-1", "2022-1", "2025-4"]
  }],

  "links": [],              // 항목 사이의 계승·개명·분화·소멸. **아직 비어 있다**

  "transitions": [{         // **모든 대상 연도에 하나씩** 있다
    "coverageYear": 2013,
    "type": "same-bloc",            // steady | same-bloc | opposition | impeachment
    "outgoing": "이명박",
    "incoming": "박근혜",
    "date": "2013-02-25",
    "note": null
  }]
}
```

#### status — 화면이 반드시 구별해야 하는 값

| 값 | 뜻 | 화면에서 |
|---|---|---|
| `verified` | 기조 절 전체를 원문 대조로 확인 | 정상 표시 |
| `partial` | 일부 항목만 확인 | 확인된 만큼만, **나머지가 비어 있음을 표시** |
| `from-preface` | 본문 손상으로 발간사에서 가져옴 | 출처를 다르게 표기 |
| `pending` | 파일은 있고 아직 작업 안 함 | **빈칸** |
| `blocked` | 원본이 없거나 못 읽음 | **빈칸 + 사유** |
| `no-section` | **그 판에 기조 절 자체가 없다** | 빈칸 + 사유, blocked 와도 달라야 함 |

**이 세 가지 빈칸은 서로 다른 사실이다.** 화면은 반드시 구별해야 한다.

- `blocked` — **2016년.** 원본 PDF에서 인쇄 22~23쪽이 통째로 빠졌다.
  제1장은 21쪽에서 끝나고 제2장은 24쪽에서 시작한다. 자료를 구하면 채워진다.
- `no-section` — **2021년.** 「2021년도 국제정세와 외교활동」은 편제가 바뀌어
  기조 절을 아예 싣지 않는다. **영원히 채워지지 않는다.** 채울 것이 없기 때문이다.

`note` 에 사유가 들어 있다. 화면은 그 사유를 그대로 보여줘야 한다.
"자료 없음"으로 뭉뚱그리면 **"정부가 그 해에 기조를 안 밝혔다"는 사실 자체를 지우게 된다.**

#### markStyle — 정부가 자기 항목에 이름 붙이는 방식

`number` · `ordinal-word`(첫째·둘째) · `bullet`(▲) · `inline-lead`(문장 속 나열) ·
`prose`(산문) · `roman`(정책목표 Ⅰ~Ⅴ) · `circled`(①~⑤)

**이 값 자체가 자료다.** 28년 동안 표기 방식이 일곱 번 바뀌었다는 사실이
"정부가 우선순위를 어떻게 말하는가"의 기록이다. 화면 어딘가에 드러나야 한다.

#### flags

`lead-only`(리드 문장에서만 확인) · `heading-only`(소제목만, 본문 인용 미수집) ·
`partial` · `ocr`(OCR 유래, 오탈자 가능) · `from-preface` · `title-lost`

## 서술 규율 — UI가 어떻게 생기든 지킨다

이건 스타일 가이드가 아니라 **계약**이다.

1. **모든 항목에서 원문과 출처로 내려가는 경로가 있어야 한다.**
   출처는 발간분·장·절·쪽까지 표기한다.

2. **인용은 원문 그대로 보여준다.** 요약·의역·윤문 금지.
   `(…)` 는 생략 표시이자 "원문의 이 자리에 쪽 머리글이 끼어든다"는 기록이다. 그대로 둔다.

3. **우리 목소리로 인과를 주장하지 않는다.**
   - ✗ "정권이 바뀌어서 순위가 바뀌었다"
   - ✓ "2025년 백서는 북핵을 4번에 두었다"

4. **집계 통계·자체 산출 순위를 만들지 않는다.**
   화면에 나오는 숫자는 **문서에 인쇄된 번호뿐**이다.
   평균 순위, 유지율, 변동폭, 빈도, 워드클라우드 — 전부 만들지 않는다.

5. **교체가 없던 해도 같은 형식으로 볼 수 있어야 한다.**
   `transitions` 에 `steady` 가 21개 있는 이유다. 대조군 없이 교체만 보여주면
   독자가 인과를 읽게 된다. "평시엔 이만큼 변하는구나"를 직접 비교하게 하는 것이
   인과 주장을 피하는 방법이다.

6. **아직 채우지 않은 연도는 비어 있음이 보여야 한다.** 있는 것처럼 보간하지 않는다.

7. **정권을 정당 색으로 칠하지 않는다.** 색은 시간이나 줄기를 나타내고
   정치적 함의를 넣지 않는다.

## 시각화 — 무엇을 만들 수 있는가

규율 4번 때문에 "데이터 분석 대시보드"의 흔한 도구들이 대부분 금지된다.
대신 **배열 자체를 보여주는 것**에 집중한다. 계산하지 않고 배치만 해도 드러나는 것들:

- **순위 이동 궤적** — 각 줄기가 28년간 몇 번 자리에 인쇄됐는지 잇는 선.
  세로축은 인쇄된 번호(1이 위). 한반도 줄기가 1998년 2번 → 1번 유지 → 2025년 4번으로
  내려가는 것이 선 하나로 보인다. 우리가 계산한 값은 하나도 없다.
- **줄기 생몰 띠** — 어느 줄기가 언제 나타나고 사라지는가. 존재·부재만 표시.
  `iraq` 는 2003~2004년에만 있다.
- **정권 이음매 전후 대조** — 교체 직전 해와 직후 해의 항목 목록을 나란히.
  `steady` 인 해도 같은 형식으로 볼 수 있어야 한다(규율 5).
- **연도 카드** — 그 해 항목 전부를 인쇄된 순서대로. 각 항목에 원문 인용과 출처.
- **빈칸의 표시** — `pending` 과 `blocked` 를 서로 다르게, 그리고 `verified` 와도 다르게.

**만들지 않는다:** 평균 순위, 유지율, 순위 변동 지수, 빈도 차트, 워드클라우드,
정당별 비교 통계, 예측, 추세선.

## 지금 데이터 상태 (2026-08-15)

```
28개년 골격    1998~2025, 결손 없음
항목 채워짐    26개년 141개 — 원문 대조 282건 전건 통과
  1998(4) 1999(5) 2000(5) 2001(6) 2002(6) 2003(8) 2004(9) 2005(3)
  2006(5) 2007(3) 2008(3) 2009(6) 2010(7) 2011(6) 2012(4) 2013(6)
  2014(5) 2015(6) 2017(5) 2018(4) 2019(4) 2020(5) 2022(6) 2023(7)
  2024(6) 2025(7)
비어 있음      2개년
  2016  blocked     원본 22~23쪽 결손 — 자료를 구하면 채워진다
  2021  no-section  그 판에 기조 절이 없다 — 영원히 채워지지 않는다
links          0개 — 항목 사이 연결은 아직 판정 전
```

**26개년은 완성됐고 나머지 2개년은 성격이 다르다.**
2016년의 빈칸은 "아직", 2021년의 빈칸은 "원래"다.
화면이 이 둘을 같게 그리면 사실을 하나 지우는 것이 된다.

`status` 가 `partial` 인 해(2001·2005·2006·2007·2008)는 항목 일부만 수집됐다.
`flags` 의 `heading-only` 는 소제목만 있고 본문 인용이 아직 없다는 뜻이다.
**둘 다 앞으로 채워진다. 화면은 그때 저절로 좋아져야 한다.**

`links` 가 비어 있으므로 연결선을 전제로 한 화면은 만들지 않는다.
대신 `streams[].members` 로 같은 줄기를 이을 수 있다.

## 기술 조건

- 정적 사이트. 서버도 DB도 없다. `data.json` 하나를 fetch 해서 렌더한다.
- `data.json` 은 71KB. 앞으로 커져도 200KB를 넘지 않는다.
- 반응형. 연구자는 노트북, 학생은 휴대폰으로 본다.
- 인쇄·PDF 저장이 되면 좋다. 인용하려는 사람들이라서.
- 한국어가 기본. 원문에 한자(江澤民)와 영문 병기(아세안(ASEAN))가 섞여 있으니
  글꼴이 이것들을 감당해야 한다.

## 마지막

이 서비스의 가치는 "AI가 백서를 분석했다"가 아니라
**"외교부가 인쇄한 번호를 그대로 보여준다"** 에 있다.

독자가 화면을 보고 "정말인가?" 하면, 그 자리에서 원문과 쪽수를 보여줄 수 있어야 한다.
그게 안 되면 다른 게 아무리 좋아도 실패다.
