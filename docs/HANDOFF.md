## ▶ 기능 2 — 무엇을 보여주나

주석님 명세 그대로 세 장면이다.

```
① 정권마다 무엇을 다뤘나   절 931개를 13줄기로 묶어 37년을 쌓았다
                          정권 경계마다 세로선. 비중(%)/절 수 전환
② 해마다 얼마나 달라졌나 ⭐ 34쌍의 거리. 교체는 주황, 1위는 빨강
③ 그때 들고 난 말          ②의 막대를 누르면 따라 바뀐다
```

**이야기의 핵심은 두 예외다.**

```
2019 → 2020   0.6568   문재인 정부 안   ← 코로나. 2위의 두 배 가까이
                       새로: 코로나·방역·화상·비대면
                       사라짐: 국빈·아세안·외교장관회담
1997 → 1998   0.1591   김영삼→김대중    ← IMF 한복판이라 정권이 바뀌어도 안 바뀜
```

정권 교체 8건 중 6건이 34쌍 중 상위 11위 안에 든다.

| 교체 | 거리 | 순위 |
|---|---|---|
| 노무현 → 이명박 (2007→08) | 0.3570 | **2위** |
| 문재인 → 윤석열 (2021→22) | 0.3405 | **3위** |
| 이명박 → 박근혜 (2012→13) | 0.2918 | **6위** |
| 박근혜 → 문재인 (2016→17) | 0.2918 | **7위** |
| 김대중 → 노무현 (2002→03) | 0.2773 | 8위 |
| 노태우 → 김영삼 (1992→93) | 0.2451 | 11위 |
| 윤석열 → 이재명 (2024→25) | 0.1598 | 22위 |
| 김영삼 → 김대중 (1997→98) | 0.1591 | 23위 |

**밝히지 않으면 사고 나는 것** — 낱말이 달라졌다는 것이 곧 정책이
달라졌다는 뜻이 아니다. 대통령·장관 이름도 낱말이라 정권이 바뀌면
반드시 달라진다. 화면 각주에 적어 두었다.

## ▶ 목차 색인 — 새로 생긴 것

37개년 백서의 장·절을 모은 `corpus/index.jsonl` (932절).
낱말로 37년을 한 번에 뒤질 수 있다.

```
'북핵'  → 1993~2003 제3장 안의 한 절   (지역·정세 아래)
          2004~2016 제2장 제1~2절      (앞으로 올라옴)
```

**백서가 그 사안을 몇 장에 두었는지가 곧 비중의 변화다.**

목차가 실린 자리는 해마다 다르다. 줄마다 `출처` 를 남겼다.

```
① 목차 전용 파일     8개년
② 본문 안 목차 쪽   14개년
③ 본문 제목줄       15개년   ← 1997~2000년은 목차가 정말 없다
```

③ 이 얼마나 믿을 만한지는 잰다 — 목차가 있는 22개년에서 정답 552개 중
496개(89.9%)를 본문만으로 되찾는다.

## ▶ 반드시 지킬 것 (어기면 사고 남)

1. **숫자를 지어내지 않는다.** 모든 값은 원본을 세어서 나온다.
2. **연도로 분기하지 않는다.** 파일을 열어 성질을 보고 판단한다.
3. **고칠 때마다 `docs/에러노트.md` 에 증상·원인·해결·배운 점을 남긴다.**
4. **정확도를 밝히지 않은 결과를 내지 않는다.** 맞은 비율과 **답을 못 낸 비율**을
   함께 적는다.
5. **Git**: `feature/설명` 브랜치 → main 머지 → push → 브랜치 삭제.
   커밋은 `유형: 제목` (feat/fix/docs/chore), 마침표 없음.
6. **작업이 길면 감시견을 붙인다.**
7. **분류율은 정확도가 아니다.** "어딘가에 붙었다" 와 "맞게 붙었다" 는 다르다.
   표본을 뽑아 원문과 대조해야 오분류가 보인다 (에러노트 36번).
