## ▶ 주석님이 원하는 것 (2026-08-16 확인)

이 프로젝트는 **웹 서비스**이고, 기능이 **여럿**이다. 지식그래프는 그중 하나다.

| | 기능 | 상태 |
|---|---|---|
| 1 | **지식그래프** — 나라·정책·사건이 어떻게 이어지나 | ✅ 돌아감 |
| 2 | **정권별 외교정책의 변화** ← **지금 만들 것** | ⬜ 착수 |

기능 2가 보여줘야 할 것, 주석님 말 그대로:

> 각 정권별로 다뤘던 외교정책 사안들이 무엇인지를 시각화해서 보여주고,
> 각 정권이 **1년이 지날 때 어떻게 변해가고**,
> 마지막으로 **정권이 교체될 때 외교정책이 극적으로 변해가는 것**을 보여주는 게 핵심

**이 문장이 기능 2의 명세다.** 세 장면이다 — ① 정권별 사안 ② 해마다의 변화
③ 정권 교체의 급변.

주석님은 비전공자다. 설명은 전문용어 없이, 비유와 표로, 짧게.
호칭은 **"주석님"**(사장님 아님).

## ▶ 기능 2 — 이미 확인한 사실 (그대로 쓸 것)

**"정권이 바뀌면 급변한다"는 데이터로 확인됐다.** 재는 방법과 결과:

해마다 낱말 분포(주제 구성)를 만들고 이웃한 해끼리 코사인 거리를 잰다.
**단, 두 가지를 반드시 걷어내야 한다** — 안 그러면 1.04배(차이 없음)로 나온다.

```
① 문체·서식 낱말   '하였다'↔'했다', '외교부는'↔'외교통상부는', '일간·개월·만불'
                   백서 편집자가 바뀌면 달라지는 말이지 정책 변화가 아니다
② 원본 결손 연도   2004년(원본 60% 결손) — 자료가 없어 생긴 변화를 정책 변화로 읽으면 안 된다
```

걷어낸 뒤 결과:

```
같은 정권 안 이웃한 해   평균 0.1975  (26쌍)
정권이 바뀌는 해         평균 0.2589  ( 8쌍)
→ 정권 교체 때 1.31배 크게 변한다
```

정권 교체 8건의 전체 34쌍 중 순위:

| 교체 | 거리 | 순위 |
|---|---|---|
| 노무현 → 이명박 (2007→08) | 0.3534 | **2위** |
| 문재인 → 윤석열 (2021→22) | 0.3392 | **3위** |
| 박근혜 → 문재인 (2016→17) | 0.2940 | **5위** |
| 이명박 → 박근혜 (2012→13) | 0.2872 | **7위** |
| 김대중 → 노무현 (2002→03) | 0.2468 | 9위 |
| 노태우 → 김영삼 (1992→93) | 0.2402 | 10위 |
| 윤석열 → 이재명 (2024→25) | 0.1580 | 22위 |
| 김영삼 → 김대중 (1997→98) | 0.1527 | 24위 |

**8건 중 6건이 상위 10위. 그런데 1위는 정권 교체가 아니다:**

```
2019 → 2020   0.6590   문재인 정부 안   ← 코로나. 2위의 두 배 가까이
1997 → 1998   0.1527   김영삼→김대중    ← IMF 한복판이라 정권이 바뀌어도 안 바뀜
```

**이 두 예외가 이야기를 좋게 만든다.** "정권이 바뀌면 바뀐다"는 뻔하지만,
"대체로 바뀐다 — 다만 코로나가 더 컸고, IMF 때는 안 바뀌었다"는 발견이다.

측정 코드는 스크래치패드에만 있다. **`scripts/policy_shift.py` 로 정식화할 것.**

### 아직 안 정한 것 — **"사안"을 무엇으로 잡을까**

주석님께 여쭸으나 답 전에 세션이 끝났다. 세 안:

| | 방법 | 성질 |
|---|---|---|
| A | 낱말 그대로 (지금 방식) | 자동·구체적(`북핵`,`중추국가`,`코로나`), 거칠다 |
| B | 주제 묶음 8~10개 (한반도·경제·다자·영사·문화…) | 흐름이 깔끔, 주제를 사람이 정해야 함 |
| **C** | **둘 다** — 큰 흐름은 주제, 파고들면 낱말 | **권장.** 시간 +1시간 |

C를 권했다. **다음 세션에서 이것부터 여쭐 것.**

## ▶ 반드시 지킬 것 (어기면 사고 남)

1. **숫자를 지어내지 않는다.** 모든 값은 원본을 세어서 나온다.
2. **연도로 분기하지 않는다.** 파일을 열어 성질을 보고 판단한다
   (2015년은 1장이 단면, 2~7장이 펼침이다).
3. **고칠 때마다 `docs/에러노트.md` 에 증상·원인·해결·배운 점을 남긴다.**
   주석님이 공부용으로 쓰는 장치다.
4. **정확도를 밝히지 않은 결과를 내지 않는다.** 맞은 비율과 **답을 못 낸 비율**을
   함께 적는다 (예: "관계 757개 중 99개에 종류를 붙였고, 그 99개는 87% 맞다").
5. **Git**: `feature/설명` 또는 `fix/설명` 브랜치 → main 머지 → push → 브랜치 삭제.
   커밋은 `유형: 제목` (feat/fix/docs/chore), 마침표 없음, 본문에 무엇을 왜.
   PR 은 안 한다 (주석님이 저장소 주인).
6. **작업이 길면 감시견을 붙인다.** 빈 폴더 하나가 밤샘 작업을 5시간 반 세운 적 있다.
